Reguły Firebase Firestore blokują zapis — odblokuj w 2 kliknięcia, aby widzieć stacje na innych urządzeniach

Oczekiwanie na uprawnienia odczytu i zapisu (permission-denied).

Krok 1: Skopiuj reguły 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Krok 2: Kliknij przycisk poniżej, aby otworzyć zakładkę Rules (Reguły) w projekcie miusic-73bfd, wklej skopiowany kod i kliknij Opublikuj (Publish). Następnie kliknij zielony przycisk „Sprawdź połączenie ponownie”.
